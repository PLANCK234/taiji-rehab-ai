# 本机教学视频试播（DEMO-V2-39）

## 来源和用途

2026-11-25，用户提供《太极动作视频（试用）.zip》，明确说明是团队自行录制的教学视频并要求加入页面设计。此授权用于当前电脑上的界面设计与试播，不等同临床内容审核、影像研究同意或向真实患者发布批准。共13段、约185秒；名称保留起势、野马分鬃、白鹤亮翅、左右搂膝拗步、手挥琵琶、左右倒卷肱、左揽雀尾、右揽雀尾、单鞭、单鞭2、云手、高探马、右蹬脚。素材排列不代表训练顺序。

素材是人物动作教学，不能冒充 [既有非指导性流程视频契约](SYNTHETIC_VIDEO_REVIEW_CONTRACT.md) 中的合成演示片。DEMO-V2-16 原发布契约和审批边界保持不变；本任务采用独立、默认关闭的本机试播区，不创建核对通过、发布、训练或完成记录。

原MOV保持不变；在仓库外生成MP4播放副本和封面，使用Mac本机 avconvert 默认元数据过滤，源文件与副本字节数/SHA-256/时长保存在私有 `source-manifest.json` / `manifest.json` 中。视频、封面及清单未加入Git或镜像，不上传。

## 操作

本机启动后以合成患者登录 `/patient`，在学习步骤选择动作。播放器支持播放、暂停、进度、全屏，另有从头重播；切换动作不自动播放，离开学习步骤或浏览器标签页时暂停。错误可重新加载。本人医护发布投影仍单独显示，试播素材不冒充已发布计划。

此版本读取已准备好的媒体目录，`manifest.json` 至少包含每项 `id`（`teaching-01` 格式）、`title`、正数 `duration_seconds`，并具有对应的 `.mp4` / `.jpg` 文件。原始文件名、路径和校验清单不传给浏览器。

设置 `.env` 中 `LOCAL_TEACHING_MEDIA_DIR=/仓库外私有目录` 后，在仓库根目录运行：

```bash
docker compose --env-file .env -f infra/compose.yaml -f infra/compose.teaching-preview.yaml up --build -d frontend
```

可选覆盖配置将目录只读挂载到前端。默认配置不启用此功能；切回不带覆盖文件的普通启动将关闭试播（已有文件保留）。不要删除数据库卷。共享或上线前须单独审查素材用途和发布流程。

## 访问与验证

视频分段和封面每次请求均检查当前患者登录、服务端本人有效绑定及Demo服务可用状态。只接受清单中的固定ID和mp4/jpg扩展名，拒绝目录跳转及越界符号链接；返回 private/no-store，支持单一HTTP字节区间。其他患者在本机开发模式同样可试播这套团队通用素材；此处并非按医护任务分配的视频库，不能用于真实患者发布。

验证：lint、typecheck、79项单元/组件测试、生产构建通过；本机Chromium专项1项通过（13片元信息、实际播放/拖动、切换暂停、390px宽度、206读取、匿名401、工作人员403、零训练/反馈写入）。未做真机Safari或临床教学适用性验收；未完整人工审核每段画面和音轨。

## 备份范围

PostgreSQL自动备份不包含视频。原ZIP、私有媒体目录及校验清单需另行保存到受保护存储设备；本任务不自动复制U盘。摄像头、动作识别、字幕/动作要点、医护选择发布和任务关联仍待接续。
