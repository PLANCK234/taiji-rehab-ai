# 产品需求文档（实施基线）

- **版本**：1.1-docs / 2026-10-30；**状态**：工程建议，待产品与临床签核
- **目标用户**：康复治疗师、临床负责人、研究助理、科研分析员、授权管理员；**不是患者自助产品**。
- **目标**：为每位研究对象建立“建档 → 安全筛查 → 客观功能评估 → 规则候选分级 → 人工确认 → 训练后反馈 → 周期末复评 → 冻结研究数据 → 离线规则优化 → 审批发布”的可追溯闭环。

## 必须具备的用户旅程
1. 研究者登录、在授权研究范围内创建研究编号，登记知情同意状态、资格和安全筛查。未同意不能采集/保存姿态照片。
2. 按有单位、操作说明、有效性状态及缺失原因的表单录入 SPPB、FRAIL、4m 步速、5 次坐站、可选 TUG/握力。SPPB 分项的官方计分公式待临床批准；未批准时只允许录入人工确认总分。
3. 使用**已发布**的 V0 SPPB 规则输出候选功能等级；单独展示风险状态和太极训练适配建议（未审定适配模板在演示环境可显示草案标签，不能有效发布）。
4. 临床人员确认/修改/拒绝，记录原因、原值、操作者、时间、规则版本；训练建议不能无审批生效。
5. 每次训练创建会话并录入实际剂量、训练状态、RPE 6–20、辅助/扶持方式、观察、主观困难和安全症状；中止后也能立刻上报事件。
6. 周期任务驱动客观复评，展示基线和终点变化；每轮结局以实测记录为准，不从训练体验推断康复效果。
7. 周期结束冻结脱敏快照，输出缺失率、结局、风险与模型比较报告；候选优化只能离线评估，临床/数据双重审批后再发布。

## 主要页面
- 登录与角色；工作台（待办、风险、待审）；受试者列表及详情；基线/复评向导；分级及建议审核；训练会话/反馈；周期管理与分析；去标识导出；规则/模型版本；姿态照片演示（禁用识别）。

## P0 功能需求
| ID | 行为 | 完成定义 |
|---|---|---|
| FR-001 | 身份、权限、研究对象授权 | 拒绝跨对象和跨角色访问并记录审计 |
| FR-002 | 建档、同意与筛查 | 未评估不视为安全；身份映射隔离 |
| FR-003 | 客观量表录入/复评 | 草稿/确认/更正、原始值、时间、单位、缺失原因 |
| FR-004 | SPPB V0 规则候选 | 完整边界、缺失处理、版本/依据 |
| FR-005 | 太极适配建议审核 | 仅已批准模板可用于真实建议；医生可拒绝/修改 |
| FR-006 | 训练会话与反馈 | 每次训练绑定周期与规则版本；允许中止与缺失 |
| FR-007 | 不适/不良事件 | 中断流程仍可报告；专业人员处理与记录 |
| FR-008 | 周期任务与终点复评 | 时间点可配置，客观前后对照 |
| FR-009 | 去标识 CSV 与趋势 | 区分缺失、冻结快照可复现 |
| FR-010 | 完整审计与数据保护 | 对更正、审批、导出留可追溯记录 |
| FR-011 | 周期冻结、分析与质量报告 | P0 数据闭环；不强制 P0 自动拟合模型 |

**FR-002 当前工程边界（S1-02）**：仅合成编号建档与模拟同意、三态筛查记录；没有真实身份映射、签署证明、获批准筛查项目或入组/安全判定。筛查记录始终待复核；照片上传关闭。

**FR-003 当前工程边界（S2-01）**：在上述合成环境和当前模拟同意下，仅录入由工作人员人工给出的 SPPB 总分（0–12 分）、有效性/缺失原因及时间，按基线或复评保存草稿、确认和追加更正。`SYN-MANUAL-V1` 只是工程标记，不是已批准量表 SOP；Q-02 未关闭时不采集自动计分分项，不生成等级、安全结论、训练建议或实际访视计划。

## P1 / 明确不做
- **P1**：姿态拍照演示壳、离线模型训练与对照评估、影子模式及模型发布管理。
- **不做**：患者端、实时太极动作纠错、自动处方/治疗、GPT 直接判定分级、线上自学习、无审查模型自动发布、生产级 RCT 随机化软件。

## 医学研究约束
- 原研究材料为约 60 例、Ⅱ/Ⅲ级、12 周干预 + 12 周随访的设计；这**不是**当前系统已获批准的研究方案。系统可提供可配置模板，但不得擅自创建或改变实际访视协议。
- SPPB 功能分级 ≠ 个体化太极处方 ≠ 安全状态；三个实体分离。
- 所有研究数据使用需先获必要审批。详见 `../research/PROTOCOL_INTERFACE.md`。
