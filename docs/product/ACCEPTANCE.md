# Acceptance criteria and test matrix

| ID | 场景 | 可验证结果 | 自动/人工 |
|---|---|---|---|
| AT-01 | 建档到复评导出 | 刷新后记录保持；历史时间线正确；编号化 CSV 有字典 | E2E |
| AT-02 | 分级边界 | 0/3→Ⅳ,4/6→Ⅲ,7/9→Ⅱ,10/12→Ⅰ；空/无效→无法判定 | 单测 |
| AT-03 | 安全筛查缺项 | 不允许显示“安全通过”；明确待复核 | API/UI |
| AT-04 | 审核/修改 | 旧候选、最终确认、原因、操作者和版本全部可追溯 | 集成 |
| AT-05 | 越权读取和导出 | 跨研究、跨对象、未授权下载 403；无敏感信息泄漏 | 安全测试 |
| AT-06 | 多次反馈 | 每会话仅一份当前反馈；更正有版本；幂等提交不重复 | API/E2E |
| AT-07 | 缺失反馈 | “未填写/拒测/中止/技术故障”等与 0/无症状分离 | 单测/UI |
| AT-08 | 安全事件 | 在未完成会话/反馈前即可上报；提醒待处理；不能自主定性 SAE | 集成/人工 |
| AT-09 | 周期冻结 | 固定抽取规则、行数、hash、缺失报告；重复读取同样数据 | 集成 |
| AT-10 | 模型发布 | 无验证/临床批准拒绝启用；旧版本结果不变 | 单测/集成 |
| AT-11 | 数据切分 | 同一受试者不能同时在训练和测试组；无未来数据泄漏 | ML 测试 |
| AT-12 | 姿态演示 | 明示“算法尚未接入”；摄像授权不满足禁止永久上传 | E2E |
| AT-13 | 备份恢复 | 独立恢复后对象/关联/权限可核对 | 演练 |
| AT-14 | 真实数据准入 | 没有伦理与安全批准时，只允许合成演示数据 | 人工门禁 |

**交付证据格式**：测试名称/执行命令/环境/提交 SHA/日期/结果/截图或日志位置；失败项保留，不得改写成通过。

S1-02 对 AT-03 的合成数据验证为：无记录返回 `not_assessed`；有任意三态记录返回 `needs_review`，没有“安全通过”状态。AT-14 的本任务验证为受保护数据库路由仅在 `local`/`test` 合成模式开放、仅接收 `SYN-` 编号、且照片上传路由不存在；完整真实数据准入仍须人工签核。

S2-01 对 AT-01 仅验证合成编号对象的基线/复评手工总分、刷新后持久化与版本时间线；周期和编号化 CSV 尚未实现。对 AT-02 仅验证原始总分 0 与缺失/无效严格区分，以及有效输入限于整数 0–12；表中分级边界属于 S3-01，Q-03/09 未关闭前不得宣称分级验收通过。

S6-01 仅为 AT-12 的纯合成回退范围：授权对象详情页展示程序绘制的虚构姿态示意，直示“姿态识别算法尚未接入”；没有文件输入、摄像调用、图片 API 或持久化。2026-10-31 前端质量检查及真实浏览器走查 10/10 通过，覆盖 UAT 第 8 步的合成范围及相关对象 URL 授权；见[验收记录](../testing/S6-01-VERIFICATION.md)。真实照片授权、采集与留存仍待 Q-01/Q-10，完整照片流程 E2E、完整 UAT 和真实数据准入未通过；不得将本次合成验收扩展为这些流程已完成。
