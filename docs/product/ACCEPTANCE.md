# Acceptance criteria and test matrix

| ID | 场景 | 可验证结果 | 自动/人工 |
|---|---|---|---|
| AT-01 | 建档到复评导出 | 刷新后记录保持；历史时间线正确；编号化 CSV 有字典 | E2E |
| AT-02 | 分级边界 | 0/3→Ⅳ,4/6→Ⅲ,7/9→Ⅱ,10/12→Ⅰ；空/无效→无法判定 | 单测 |
| AT-03 | 安全筛查缺项 | 不允许显示“安全通过”；明确待复核 | API/UI |
| AT-04 | 审核/修改 | 旧候选、最终确认、原因、操作者和版本全部可追溯 | 集成 |
| AT-05 | 越权读取和导出 | 跨研究、跨对象、未授权下载 403；无敏感信息泄漏 | 安全测试 |
| AT-06 | 多次反馈 | 每会话仅一份当前反馈；更正有版本；幂等提交不重复 | API/E2E |
| AT-07 | 缺失反馈 | “未填写/拒测/中止/技术故障”等与 0/无症状分离 | 单测/UI |
| AT-08 | 安全事件 | 在未完成会话/反馈前即可上报；提醒待处理；不能自主定性 SAE | 集成/人工 |

| AT-09 | 周期冻结 | 固定抽取规则、行数、hash、缺失报告；重复读取同样数据 | 集成 |
| AT-10 | 模型发布 | 无验证/临床批准拒绝启用；旧版本结果不变 | 单测/集成 |
| AT-11 | 数据切分 | 同一受试者不能同时在训练和测试组；无未来数据泄漏 | ML 测试 |
| AT-12 | 姿态演示 | 明示“算法尚未接入”；摄像授权不满足禁止永久上传 | E2E |
| AT-13 | 备份恢复 | 独立恢复后对象/关联/权限可核对 | 演练 |
| AT-14 | 真实数据准入 | 没有伦理与安全批准时，只允许合成演示数据 | 人工门禁 |

## 患者端验收（AT-PAT-01 及 AT-PAT-02 合成流程子集已验证，真实患者准入另行审批）

| ID | 场景 | 可验证结果 | 自动/人工 |
|---|---|---|---|
| AT-PAT-01 | 合成患者登录与本人隔离 | 只能读取绑定的本人编号；工作人员页面、其他对象、导出和未发布计划均拒绝；撤销绑定后失去访问 | API + 浏览器 |
| AT-PAT-02 | 计划与视频 | 只展示医护明确确认并发布给本人的有效版本和已审核视频；未发布、撤回、`DEMO_ONLY` 草案或无素材均不伪装为可执行指导 | API + 浏览器 + 临床人工审核 |
| AT-PAT-03 | 训练和不适记录 | 患者可保存本人实际训练与不适事实；缺失不默认为安全或完成；工作人员可按权限查看，异常处置不由系统自行判定 | API + 浏览器 + 机构流程验收 |

AT-PAT-01 已有合成患者账号、本人编号隔离、工作人员路由拒绝、绑定撤销与审计；AT-PAT-02 仅有固定不可执行卡片的医护发布/撤回、版本、本人投影及视频待添加状态。AT-PAT-03 已有合成患者本人训练与不适事实录入、追加更正、明确未知状态和获授权工作人员查看的工程子集。真实医护确认计划、审核视频、异常机构处置与真实患者准入未实现，AT-PAT-02/03 **完整标准未通过**。患者自行填写评估量表及自动获得训练建议不属于第一版。

DEMO-V2-15 在 AT-PAT-02 的合成子集增加两张固定非指导卡片的选择、明确演示确认、标题版本快照和患者本人展示；无确认或未知选项拒绝，客户端提交视频地址也拒绝。真实计划选择、临床审核和已审核视频仍未验收。

DEMO-V2-16A 仅完成[合成视频核对与播放工程契约](SYNTHETIC_VIDEO_REVIEW_CONTRACT.md)：要求可核验来源与哈希、实际人工观看、追加核对历史、发布快照及逐次本人授权。仓库无可用视频，`awaiting_review` 占位保持不变；AT-PAT-02 的视频子集尚未实施或验收。

DEMO-V2-17 对 AT-PAT-02 的合成易用性子集增加发布前条件提示：获分配医护能区分模拟同意、患者绑定与读取失败，缺条件时页面禁用新发布并可重新检查；撤回仍可操作。后端始终重新校验条件，提示不构成临床审批或患者训练许可。正式计划和视频标准未通过。

DEMO-V2-18 对 AT-PAT-03 的合成可追溯子集增加患者本人更正历史的完整展示：当前及每条旧修订分别显示保存的发生时间、训练情况、时长或未知、不适及描述、保存时间与更正原因；刷新后仍能展开旧版本核对。不推断完成、风险或机构处置，正式患者验收仍未通过。

DEMO-V2-19 对 AT-PAT-03 的合成时间一致性子集要求：患者输入的北京时间在历史中仍显示同一当地时刻，异时区设备点更正时预填一致；不修改发生时间的更正保持原瞬时值及秒数。仅为合成流程验收，正式患者标准仍未通过。

REAL-01D0 对 AT-06/07/08 仅完成合成数据的工程子范围：每会话反馈版本、未填/缺失/观测值区分、事件先于反馈独立记录、权限/幂等/持久化；测试见 [TRACEABILITY](../TRACEABILITY.md)。事件目前没有通知与临床处理闭环，不能把事实记录视为完成 AT-08 的正式处置要求。周期/规则版本关联、真实数据和临床流程仍未验收。
