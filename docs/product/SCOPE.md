# Scope, assumptions and non-goals

2026-11-26范围更新：已提供[研究伦理批件和用户授权](../evidence/CKLL-20260904.md)，开放临床分级、剂量/禁忌、AI自动方案决策及准确率模块开发，按[68–71任务](CLINICAL_AI_DEVELOPMENT_BACKLOG.md)推进。具体参数可由专家后续编辑，框架不再等待重复的开发许可；原文“自动治疗建议生效”作为无条件非目标的限制由本段更新为“仅按配置的生效策略版本运行，保留专家调参/人员覆盖”。本轮不变更运行代码。

## MVP 的核心价值

2026-11-26 用户新增方向：下一阶段优先建设 [AI视频辅助评估](AI_VIDEO_ASSESSMENT_PROPOSAL.md)，从姿态壳推进到真实模型识别、可解释候选与人工审核。此为设计范围变更，以下 P1/P2 仍描述原基线；不是已交付能力或患者自助端。
医生能知道**采什么、为什么采、什么时候采**；能在 Web 中记录、回看、导出、审核分级；研究者能在周期结束时拿到可复现的数据用于下一轮研究。

## P0/P1/P2

- 新增双端方向（2026-11-05）：现有工作人员端继续承担评估、审核与科研记录；患者端作为独立入口分阶段建设。第一版仅本人查看医护确认的计划/审核过的视频，并记录训练与不适。当前阶段先做合成数据演示，真实患者开放另受审批门槛约束。
- P0：登录/范围授权、建档/同意、安全筛查、SPPB 等评估、初始 V0 候选与医生审核、会话/训练反馈、不良事件入口、周期终点/统计导出、数据完整性/审计。
- P1：照片 UI 空壳；版本登记、离线候选训练、影子对照、模型审批发布。
- P2：经过独立验证的姿态估计任务、更多研究站点、多模态模型、经批准的统计扩展。

## 不支持
患者自行填写评估量表、家属端、未审核的视频教学、电子支付、无配置生效版本的自动建议、即时改写线上模型权重、医疗器械注册或伦理审批自动化。已授权的AI方案决策和批次回归优化是待开发范围。

## 可用性定义
P0 是“研究人员可在合规环境按批准流程录入与使用”的工程基础；临床试点必须额外满足伦理、隐私、规则和院内安全审批，不能因为部署成功而推断可以直接用于临床。

## 先决决策
正式SPPB计分配置、太极动作/剂量/禁忌参数、结局标签、数据保存/部署场所和软件角色仍需具体输入。研究伦理与本轮开发授权已记录，配置框架/AI决策/回归/评测开发可以先推进；运行版本与真实数据接入不因文档状态自动切换。
