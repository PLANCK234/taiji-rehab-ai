# Scope, assumptions and non-goals

## MVP 的核心价值
医生能知道**采什么、为什么采、什么时候采**；能在 Web 中记录、回看、导出、审核分级；研究者能在周期结束时拿到可复现的数据用于下一轮研究。

## P0/P1/P2
- P0：登录/范围授权、建档/同意、安全筛查、SPPB 等评估、初始 V0 候选与医生审核、会话/训练反馈、不良事件入口、周期终点/统计导出、数据完整性/审计。
- P1：照片 UI 空壳；版本登记、离线候选训练、影子对照、模型审批发布。
- P2：经过独立验证的姿态估计任务、更多研究站点、多模态模型、经批准的统计扩展。

## 不支持
患者端和家属端、视频教学/打卡、电子支付、自动治疗建议生效、在线模型权重更新、医疗器械注册或伦理审批自动化。

## 可用性定义
P0 是“研究人员可在合规环境按批准流程录入与使用”的工程基础；临床试点必须额外满足伦理、隐私、规则和院内安全审批，不能因为部署成功而推断可以直接用于临床。

## 先决决策
正式 SPPB 计分细则、太极动作/安全规则、研究时间点与结局定义、数据保存/部署场所、影像授权、负责人审批权限。未确认则演示数据可用，临床相关功能维持锁定。
