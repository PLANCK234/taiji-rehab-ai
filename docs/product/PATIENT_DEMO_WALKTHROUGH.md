# 合成医护与患者双端演示操作说明

适用范围：本机 Demo 的虚构对象和账号。负责人可以用这份说明走查页面；所有卡片与自报均为合成流程测试，不能用于真实患者训练。现阶段没有经医护确认的可执行计划，也没有可播放的审核视频。研究工作台的 `DEMO_ONLY` 动作方案不会自动发到患者端。

## 准备

1. 按根目录 [README](../../README.md) 启动本机 Demo，打开 `http://127.0.0.1:3000/login`。点击“工作人员演示账号”或“患者演示账号”即可填入对应邮箱；密码取本机 `.env` 的 `DEMO_PASSWORD`，不是 Windows 登录密码。建议用两个独立浏览器会话，避免账号切换影响画面。
2. 患者账号只绑定 `SYN-001`。工作人员登录后在工作台打开这个对象的详情页，找到“患者端合成发布流程”。先核对页面的“当前模拟同意”和“合成患者绑定”；缺少模拟同意时，在同一对象页的“添加模拟同意记录”保存一条模拟同意，再点“重新检查发布条件”。不要为演示创建真实身份或同意。
3. 如果需要从“未发布”开始录屏，先查看当前状态。已有发布可在勾选合成流程测试确认后点“撤回测试卡片”；发布和撤回都会留下新版本，不会抹掉历史。

## 推荐录屏顺序

| 镜头 | 操作 | 应看到的结果 |
|---|---|---|
| 医护选择 | 在 `SYN-001` 详情页选“演示卡片 A”或“演示卡片 B”，勾选“本次选择仅用于合成演示”和“这只是合成流程测试” | “发布所选测试卡片”可用；页面显示所选卡片和发布条件 |
| 医护发布 | 点击“发布所选测试卡片” | 状态变为“合成卡片已发布”，版本增加；历史保留 |
| 患者查看 | 在独立会话以患者账号登录，打开“我的康复空间”，必要时刷新 | 只见本人 `SYN-001`、当前所选卡片标题和测试文字；视频区域显示“视频待添加” |
| 患者记录 | 在“训练与不适”表单选择北京时间、实际训练情况、不适情况；已知时填写实际分钟，必要时填写不适描述，然后保存 | 页面出现保存成功提示及当前记录；留空时长表示未知，不代表 0 分钟 |
| 患者更正 | 点击该记录“更正”，修改事实并填写以 `SYN-` 开头的更正原因，保存后展开“查看旧版本” | 新版为当前事实，旧版仍可核对；记录按当前版本保存时间排序 |
| 医护查阅 | 刷新 `SYN-001` 详情页，查看“患者自报训练与不适” | 能看到当前版本和可展开的旧版本，发生时间与保存时间均标明北京时间 |
| 医护撤回 | 回到“患者端合成发布流程”，勾选合成流程测试确认并点“撤回测试卡片”；刷新患者页 | 患者不再看到测试卡片；本人既有自报记录仍可查 |

## 解说边界与常见情况

- 可以说：“现在演示了工作人员选择、发布和撤回测试卡片，以及合成患者记录实际训练和不适、工作人员查看修订历史。”
- 不能称卡片为已审核的康复方案，也不能称“视频待添加”为视频审核通过。患者自报不触发自动风险判断、通知或医护处置。正式功能仍受 [验收矩阵](ACCEPTANCE.md) 中 `AT-PAT-02/03` 的审批与实现条件约束。
- 发布按钮灰色时，先看页面的模拟同意和绑定提示，再确认已选择卡片并勾选两个确认框。`SYN-001` 是现有患者账号的绑定对象；其他编号即使有模拟同意，也可能没有患者绑定。
- 患者页显示“无法访问”时，账号绑定可能已撤销或服务不可用。不要为演示重新启用已撤销绑定；按 [README](../../README.md) 检查合成环境并换用有效夹具。

操作依据：[现有研究人员七步流程](DEMO_USER_FLOW.md)、[双端验收边界](ACCEPTANCE.md)、`frontend/e2e/patient.real.ts` 的真实浏览器流程。此文档只指导演示，不替代临床方案、机构流程或真实患者使用说明。
