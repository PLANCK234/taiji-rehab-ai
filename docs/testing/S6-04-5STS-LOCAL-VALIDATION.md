# S6-04 首个五次坐站本机样本验证

日期：2026-11-17（北京时间）

## 样本边界

- 编码：`SYN-5STS-001`。
- 用户声明：本人/志愿者演示，已允许用于本机技术测试；侧面视角，实际完成 5 次，没有剪辑或慢放。
- 本报告不保存原视频、文件名、身份或像素。原视频只由浏览器本地读取；派生 JSON/CSV 位于 Git 忽略的本机 `exports/s6-04/SYN-5STS-001-20261117/`，不作为仓库数据集或 Research 快照。
- 该声明不是伦理批件、真实患者同意或机构影像治理批准。本轮不生成 SPPB 分数、临床分级、动作合格线或训练建议。

## 执行方式

共享本机 Demo 使用既有 PostgreSQL 卷、FastAPI 和启用 `POSE_PROTOTYPE_ENABLED=true` 的 Next.js 生产构建。合成工作人员进入 `SYN-001` 的本地视频姿态实验室，以固定 MediaPipe Pose Landmarker Full float16 模型按 10 Hz 分析；浏览器下载派生 JSON/CSV。请求监视从进入姿态实验室后开始，分析期间没有非 GET 请求。

S6-09 增加角度—时间曲线后再次用同一文件本机复验。选择右膝时页面生成 4 个连续折线段、0 个孤立已知点，与上述零散缺失区间一致，说明实现没有跨缺口连线或把未知补为 0；分析期间仍没有非 GET 请求。该可视化只用于观察数据完整性和辅助人工标注，不构成自动计次或阶段识别。

S6-10 增加视频—曲线时间联动后再次复验：程序化播放定位到 1.2 秒时，滑块值和曲线游标同步；再由滑块定位到 4.0 秒，视频实际时间为 3.999999 秒，曲线游标由横坐标 90.35 前进至 179.84，骨架使用同一最近采样逻辑。分析与联动期间仍没有非 GET 请求。该定位不生成阶段或次数标签。

S6-11 增加人工标注曲线位置后再次复验：在 4.0 秒添加自定义“人工检查点 A”后出现 1 个曲线标记和定位按钮；先回到 0 秒再点击按钮，视频定位到 3.999998 秒且滑块值为 4；删除标注后两种呈现均消失。全程没有非 GET 请求。这个自定义事件只验证界面行为，不作为五次坐站阶段真值。

S6-12 增加本地标注 CSV 恢复后再次复验：当前存在标注时导入禁用；导出并删除后，导入恢复 1 条标注和 1 个曲线标记。专项脚本故意把 CSV 中模型角和绝对差值改成 0°/100°，导入后按当前视频重算为 170°/70°，说明没有信任陈旧派生值。全程没有非 GET 请求；这些人工字段仍不是正式阶段真值。

S6-13 将导入改为预览确认后再次复验：预览只显示 1 条、4.0–4.0 秒、1 条人工角和右膝，没有显示测试用敏感文件名；确认前和取消后曲线标记均为 0，第二次选择并确认后恢复为 1。模型角/差值仍重算为 170°/70°，全程没有非 GET 请求。预览没有审核事件语义。

S6-14 增加人工标注编辑后再次复验：进入编辑时视频回到 3.999998 秒；把事件和参考关节从右膝改为右髋后保存，仍只有 1 行和 1 个曲线标记，导出时刻保持 4000.0 ms，右髋模型角重算为 164.5°。再次编辑后取消，没有保存临时事件名。全程没有非 GET 请求；编辑未改变事件的人工性质。

## S6-04 原视频时间标注与模型对照

2026-11-17 在断网请求的本机 Edge 中以 0.1 秒间隔查看视频，先观察画面并记录直立过渡，再读取既有模型 CSV。用躯干和腿从伸展过渡至可见直立姿势的过程给出时间区间。座面接触点受画面限制，下表的离座和坐回仅记录可见的抬升或回到坐姿，精确接触时刻保留未知。本轮由助手单次目视标注，尚无独立复核。

能辨认出 5 次直立。视频首帧已前倾，首次起身启动时刻无法确定。第五次直立距视频开头约 14.2–14.4 秒。浏览器检测到 1 条音轨，本轮只核对画面，口令时刻未核实。LIFE 研究手册采用发出口令至第五次直立的计时口径，故本轮没有正式 SPPB 用时。[LIFE 研究操作手册](https://agingresearchbiobank.nia.nih.gov/studies/life/documents/download/Manual_of_Procedures_Main_Trial/Chapter_16_Physical_Measurements_v5.0.pdf/)

五个模型取峰窗口由目视坐姿间歇划定，依次为 0.0–2.7、2.8–6.25、6.3–9.75、9.8–12.85、12.9–16.52 秒。各窗口分别取右髋和右膝最大已知角的时刻。右髋峰均比对应直立过渡区间的末端晚约 0.2–0.5 秒，右膝峰在第 3、5 次落入区间，其余 3 次晚约 0.1–0.5 秒。直立后仍可能继续出现更大的估计角度。这些差值只描述峰值与目视区间的相对时间。窗口由目视提供，模型独立计次和事件计时尚未验证。模型角度来自估计的世界坐标，缺少同条件的参考角，本轮未报告角度误差。

## 结论与缺口

该样本证明现有浏览器原型能读取一段实际侧面五次坐站视频，持续输出单人骨架、可见侧关节角、轨迹、覆盖率和导出，并保持无视频上传。它同时证明“整体人体检出率高”不等于“双侧运动学完整”：侧面遮挡可使远侧肢体整段未知，足部在末段也可能丢失。

完成 S6-04 还需要核实口令、独立复核标注、确定可比角度参照、验证独立计次和事件计时，并补充太极及多条件失败样本。正式研究口径待团队确认。
