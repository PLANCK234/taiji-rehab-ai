# DEMO-V2-43 未保存反馈的离开提醒

## 范围和行为

用户明确要求继续实现未保存反馈离开提醒。当前仅跟踪本人反馈表单：新表单空白/未知状态不提醒，发生时间或训练/不适状态有内容时提醒；只打开已有记录更正不提醒，更正字段变化时提醒，改回原值则解除。隐藏的无效关联字段不当作待提交事实。

患者页通过独立客户端Provider汇总当前表单状态，用页内通知标明未保存。刷新、普通关闭/离开文档由beforeunload请求浏览器原生确认；四步切换不跳文档、不弹窗，原输入继续保留。退出登录先进行明确确认，取消时不发logout请求；成功退出才解除提醒，退出失败保留提醒。工作人员原LogoutButton未传入回调时行为不变。

保存失败继续提醒，保存成功后按剩余草稿判断：如果只是更正一条记录、另有未提交新增草稿，更正保存后仍提醒新增草稿。为避免直接丢失更正，取消或切换历史更正前也确认；进入历史时原新增草稿由状态保存。

## 边界

- 只提醒，不自动保存，不写localStorage/sessionStorage或服务器；确认离开后仍会丢失未提交内容。
- 原生提示文字和触发条件由浏览器控制，需要用户交互；手机系统强制结束应用、崩溃等不保证触发。
- 不阻拦强制会话失效/权限撤销，不声称拦截全部SPA历史路由或浏览器返回行为；本次明确覆盖普通文档刷新/关闭及患者退出登录。
- 单一本人反馈表单的保护，不自动扩展至其他业务输入；无数据库、后端和接口字段变化。

## 本机确认步骤

刷新患者页，进入反馈，填写一个合成测试时间但先不保存。应看到未保存提醒；切去学习再回来，输入仍在且不弹窗。点击退出登录，选择取消，应停留原页并保留内容。尝试刷新时选择留在页面，输入也应保留；提示可能使用浏览器固定文案。实际保存成功且无其他草稿时，提醒消失。电脑浏览器可先验证，目标手机仍须独立实测。
