## 准备

- 使用团队授权且手机可访问的 HTTPS 合成演示环境，开启 `POSE_PROTOTYPE_ENABLED`，使用工作人员演示账号与已分配的合成档案。当前本机 Compose 只监听 `127.0.0.1`，此地址在手机上指向手机本身。
- 准备获授权的演示画面，手机固定，穿鞋即可。记录机型、系统版本、浏览器版本和演示版本。
- 从研究工作台进入合成档案，点击「打开本地视频姿态实验室」，找到「实时摄像头骨架验证」。

## 操作与通过条件

| 项目 | 实测操作 | 通过条件 |
| --- | --- | --- |
| 授权与恢复 | 在站点权限未设定时，确认页面授权并开启预览，先拒绝，再按浏览器设置允许并重试 | 拒绝时有提示且没有预览；改为允许后可开启预览 |
| 摄像头选择 | 先尝试默认摄像头，停止后再明确选择后置并开启 | 两次分别记录实际打开的镜头；后置不可用时有提示，改选默认可重试 |
| 竖屏取景 | 竖持手机，先预览，再调整到全身入镜 | 竖屏视频使用竖向预览框，按钮可触达，开始识别前没有骨架 |
| 识别与可见性 | 点击「开始识别」，观察骨架，再让脚短暂离开画面并重新入镜 | 能看到随画面变化的骨架；在可重复出现的遮挡下记录可见性提示是否变化 |
| 停止与离开 | 分别在仅预览和已识别时停止，随后另开一次预览并返回档案 | 页面关闭预览，设备或浏览器摄像头指示结束；再次进入需手动开启 |
| 摘要 | 识别后停止并导出 JSON，在「核对实时分析摘要」重新打开 | 仅预览停止时无摘要；有采样的识别可导出并核对计数、观察时长与可用角度 |

## 结果记录

实时检出调参复测：在同一台手机保持距离和光线，用相同的短动作分别测试正面、侧身、穿外套正面、穿外套侧身。各次记录采样数和检出数、骨架连续性以及「暂未识别到人体」与「部分关键点不可见」提示。当前取景检查计数仍沿用双足与头部均可见的判定，侧身不满足时可同时检出人体。再短暂离开画面，观察是否出现明显误检。测试可直接用实时摄像头。

患者闭环补测：在手机拒绝摄像头授权后，点击「跳过摄像头并填写记录」，提交关联当前版本的合成反馈。用工作人员账号从发布历史核对同版本，确认该记录显示「未提交姿态摘要」。有摄像头预览但模型加载失败时，沿用同一个入口。测试用记录保持训练事实由演示者填写。

每项填写通过、失败、未执行或设备不适用。失败时记录步骤、页面提示与是否可复现。浏览器未提供权限重试或摄像头指示时，记录实际观察和无法核实的部分。可记录首个骨架出现的大致等待时间及卡顿现象，用于比较设备；当前没有性能通过阈值。记录中不放账号凭据、原始画面或个人信息。

患者端合成训练流程已接通。按同一已发布任务完成手机端执行、反馈和工作人员核对后，记录闭环验收结果。
