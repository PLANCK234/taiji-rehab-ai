# 五次坐站候选测量验证（DEMO-V2-63）

## 领域判断与交付范围

SPPB 的坐站是专项测试，普通太极视频没有五次坐站试验，不能据其关节幅度计算 SPPB 分。本次仅实现独立后端测量函数与离线命令，输出 `MODEL_CANDIDATE`，`sppb_score=null`。现有 Web 页面、API、数据库和分级行为不变。评分表、逐项复核到人工草稿的完整闭环仍待后续任务。

## 可验证目标与结果

测试文件：`backend/tests/test_sppb_measure.py`；全部为人工构造关键点，无真人视频。

2026-11-26 实际执行：后端 `ruff check .` 通过；全量 `pytest -q` **110 passed / 6 opt-in skipped**（66.11s），其中新增测量测试 15 项。CLI 子进程复算也在测试中真实运行。仅有现有 Starlette/httpx 弃用警告。跳过的数据库 opt-in 测试本轮未运行；无数据库变更。

首轮单帧脉冲夹具失败：其余0.7位置在 P10/P90 相对缩放后仍构成连续高状态，实际上不是单帧脉冲。改为仅一帧高、其余静止的真实脉冲夹具后通过；同时修正一处 Ruff 行长，最终结果如上。

## 参数与输出语义

`SitStandOptions` 保存本版全部信号参数：visibility=0.5、最大间隔450ms（兼容当前文件200ms及摄像100ms）、连续2样本、相对起身/低/高位置0.05/0.3/0.8、最小髋高变化0.15躯干长度、最小膝角变化10°。相对范围由本段有效帧 P10/P90 估计，左右膝选有效配对较多侧；同数选右。高度用固定的躯干长度中位数归一化，避免逐帧分母变化制造运动。

手部参数：腕距对侧肩≤0.8躯干长度是交叉代理，任一腕距髋≤0.45躯干长度是撑扶疑似。支撑检查先于交叉代理；它们不是临床判据。需要固定、直立机位和能看到肩髋膝踝及手腕的取景。手部疑似与未知必须人工核对。

第五次时刻为连续高状态确认后的首个采样时刻；自动起点为连续超过起身阈值的首帧，属于离散采样候选，不是真实物理起点的精确真值。人工起点需在初始坐姿与首次站起之间。最多返回首五次候选；质量窗口包含第五次确认帧，前后额外帧不参与失败判断。任何期间丢帧仍会使本次用时未知，不能把不同片段拼成一次完成。

输出包含输入 SHA-256、完整参数、算法版本、候选时刻及数量、所选侧、失败原因、可用帧比例、单人帧比例、关键点平均可见性。这些比例是质量描述，不是已校准的正确概率。即使有候选用时，`protocol_compliance=unverified`，必须人工审核。

## 未验证与后续

- 未进行人体/老年人、辅具、椅子、遮挡、侧拍、机位移动、iPhone/Android/微信实机的精度验证。
