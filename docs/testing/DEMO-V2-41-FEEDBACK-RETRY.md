# DEMO-V2-41 患者反馈错误提示与失败重试

## 行为

既有本人反馈接口和更正历史不变，无数据库迁移。必填时间、非负整数分钟、报告不适时的1–500字描述、更正原因的SYN-前缀及5–500字长度，与既有后端约束一致；0分钟有效、留空仍未知。错误在字段旁显示，以aria-invalid/aria-describedby关联，提交定位首个无效项，不向服务端提交无效表单。

提交期间禁用全部填写控件、保存、取消和历史更正，并用同步锁防止重复提交。保存15秒未完成时中止浏览器等待，恢复可手动重试；超时不表示服务器一定取消，必须显示“尚无法确认保存结果”。失败保留输入，不虚构成功。同一内容的原路径/请求体/幂等键在重试时保持不变，修改内容会更换键。跨页面刷新/退出不保证保留草稿或提交编号，不宣称跨刷新幂等。

401提示在新标签页登录并返回；403提示检查绑定/模拟同意/权限；422提示核对输入；429提示稍后重试；网络/5xx明确结果未确认。409不自动重试：重新读取历史后，用户可明确采用最新版本作为更正依据，保留所填内容但不自动提交；新增冲突则需明确核对历史后才能继续。读取历史临时失败也保留当前组件内的草稿，恢复读取后继续显示。页面授权失效后跳转登录仍按原认证边界处理。

## 本机查看

刷新localhost:3000/patient，进入反馈，不填发生时间点击保存，应出现字段提示并聚焦，不创建记录。保存失败会显示保留输入的说明和重试入口。无需为了验证此功能在现有数据库故意制造网络故障；异常路径已在独立库/模拟请求中测试。浏览器刷新会丢失未提交内容，保存成功的历史仍由数据库读取。

仅完善既有独立事实表单，不增加疲劳/疼痛量表或任务关联，不改变临床/Research边界。本机只更新前端，无既有反馈修改或测试记录注入。
