# ADR-0017 — 合成患者事实记录与医护观察分源

2026-11-05；状态：合成工程决定，非临床或机构处置批准。

## 背景与选择

DEMO-V2-13 需要患者自行记录已发生训练和不适。既有 `training_sessions` 明确标记 `manual_staff_entry`；把患者文字写入该表会混淆来源，并可能让未填信息被误当完成或安全。Q-04 仍未定义机构处置流程和时限。

## 决定

新增独立、追加式患者自报修订表。本人活跃绑定和当前模拟同意才可写入；每次写入使用 CSRF、幂等键和预期版本，更正需合成原因。训练情况与不适情况都要求明确选择“做了/未做/未知”“有/无/未知”；无记录本身为未知，时长可保持空值。获研究与对象分配的工作人员只读查看全部版本。自由文本不进入现有编号化 CSV；不自动创建医护训练观察、完成状态、安全事件或处置提醒。

## 后果与复核

可验证 AT-PAT-03 的合成数据录入、隔离与修订子集，但并非真实患者随访或异常处置服务。取得 Q-04、Q-07、Q-14 与机构流程批准后，重新设计患者提示、通知责任、处置审计和保留规则；不得直接把合成输入接口作为真实患者服务开放。

2026-11-07 REAL-01F3 扩展：单对象实时 Demo CSV 仅纳入患者自报的结构化状态、时间、时长及全部修订，继续排除不适自由文本和更正原因；患者角色本身无导出权限。此扩展不改变上述真实患者与机构处置边界。
