# ADR-0016 — 端侧真实姿态模型与后端几何证据

日期：2026-11-26。状态：工程实施决定，任务`DEMO-V2-10/11`；不代表临床评分发布。

## 背景与选项

用户要求直接实现可验证的识别。方案15只规划了系统，当前落实最小闭环。比较：大模型视频评分缺少可复算依据；从零训练缺标签；预训练姿态模型配几何指标可立即验证。

## 决定

采用固定版本MediaPipe Pose Lite，浏览器classic Worker中实际推理，避免阻塞主界面；模型/WASM/SDK从本站加载，构建时核验模型哈希。SDK CommonJS内容通过显式exports适配在Worker中加载，以`.js`提供正确MIME。CPU委托为首个测试路径，移动设备性能仍待验证。

新建`pose_analyses`保存输入、输入哈希和服务器计算结果，`pose_reviews`追加人工观察复核。仅接受合成Demo来源；不上传原视频，关键点按参与者权限保护。新入口`/participants/{id}/ai-assessment`，保留旧pose-demo及其历史测试边界。

指标为图像平面宽高比校正的肘/肩/膝角度中位数、P5–P95活动幅度、可见帧比例和观察时长。可见性0.5、至少3个有效帧、相邻≤1秒是版本化工程参数，不是疾病阈值；不因慢速、小幅、坐位自动扣分。多人画面不取第一个人猜对象，缺失不插补。暂不输出SPPB/阶段/治疗建议。

## 后果

可从视频追到关键点、几何值、版本和人工决定。不能从图像平面角度直接推断真实三维关节角、肌力/重心、动作规范度或临床分期；端侧输入可被修改，哈希只证明记录内容一致，不证明采集真实。原视频不保存，刷新只能回看骨架证据。

## 重新评估与负责人

有专家逐项评分表和阶段映射后进入任务12；目标设备性能不足、转身/遮挡误差明显时比较Full/Heavy或其他模型。真实数据、影像留存和模型临床发布仍由项目/临床/数据负责人分别确认。验证方案见[AI姿态验证](../testing/AI_POSE_VALIDATION.md)。
