# ADR-0028：记录伦理批件，开放临床AI开发与专家调参

2026-11-26。任务DEMO-V2-67；状态：按用户明确授权采纳的开发范围决定。

## 依据

[CKLL-20260904](../evidence/CKLL-20260904.md)载明同意实施本项目，含分级、处方、训练参数调整、摄像头AI评估和周期复评。用户同时明确确认临床分级、训练剂量/禁忌、AI决定方案及准确率模块可以开始开发，专家后续调整参数。

## 决定

1. 将旧的“没有任何伦理材料，因此上述功能不能开发”更新为DEVELOPMENT_AUTHORIZED；S3-01解除该旧阻断。具体规则/量表/剂量/禁忌/软件责任角色以CONFIG_PENDING_EXPERT_TUNING追踪，可先实现参数框架，不能反复要求相同开发许可。
2. 新增68临床参数注册/编辑、69AI自动方案、70训练结局回归、71评测展示/宣传引用。66的3D任务保留但不是68前置。
3. 允许可复现的模型随机初始化和合成初始参数；临床规则值及模型权重分开管理，专家调整追加新版本。实际输出引用有来源的配置，不把随机仿真值作为医学事实。
4. AI自动决策为产品目标；按生效策略版本运行，保留人工覆盖与回滚。策略版本生效与每次工作人员复核不是同一概念，不一概强制每条输出都先人工确认。
5. 回归以客观随访结局为配置目标，按对象和时间隔离、比较固定基线/正则回归及候选。训练产生候选策略版本，不以即时自报体验冒充功能改善；观测关联、识别表现和临床效果分开报告。
6. 评测及对外材料模块开放开发；实际准确率必须来自对应版本的独立实测报告。批件本页没有识别率，不由审批认可生成数字。
7. 所有更新通过PR；不改写旧历史。本轮仅文档/证据，不改变API、数据库、运行开关或发布任何新临床参数。

公开副本遮盖负责人联系方式，原件保持不变；批号/内容/日期/结论和文件哈希可追溯。具体计划与验收见[待开发文档](../product/CLINICAL_AI_DEVELOPMENT_BACKLOG.md)。
