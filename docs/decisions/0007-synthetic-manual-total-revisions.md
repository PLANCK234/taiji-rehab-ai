# ADR-0007 — 合成人工总分的只追加版本

**日期**：2026-10-30。**状态**：工程实施决定；不代表临床、伦理或研究方案批准。

## 背景

S2-01 需要在 Q-02 量表 SOP 未批准时支持评估草稿、缺失、复评和可追溯更正。PRD 只明确允许先录入人工确认的 SPPB 总分。将空值写成零、覆盖旧记录或从总分推导等级，都会越过该边界。

## 选项

1. 在评估主表上原地更新一个当前值：表结构简单，但历史和草稿/确认来源难以审计。
2. 为每次变更追加完整测量快照：读当前值需按版本排序，保存更正与确认的完整上下文。

## 决定

采用 `assessments` 头表加 `assessment_revisions` 只追加快照。当前版本由最大 `revision_no` 得出；确认复制当前已录入草稿为新版本，保留操作者和 UTC 时间。有效人工总分限制为整数 0–12 分和实际测量时间；未记录、缺失、无效与零分独立。修订需要显式 `expected_revision`、幂等键、当前模拟同意和对象授权。`SYN-MANUAL-V1` 只作为合成工程标记。不给出自动分项、等级、安全或训练建议。

## 后果

时间线可以在刷新与服务重启后复现，更正可归责。当前版本读取需要一次排序查询；每次确认产生新行。`0004_manual_assessments` 的回退会删新表，只能在空的临时测试库演练，生产/真实数据迁移和保留策略仍需批准。

## 重新评估触发条件与批准人

Q-02 获签核的量表 SOP、实际研究访视方案、真实数据准入或数据保留策略一旦确定，应重新设计多指标和协议版本。工程实现由开发团队负责；临床与伦理批准人尚未指定，本 ADR 不代替其签核。
