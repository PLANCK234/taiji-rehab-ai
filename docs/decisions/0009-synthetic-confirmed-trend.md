# ADR-0009 — 合成人工总分趋势分离确认与草稿

**日期**：2026-10-31。**状态**：本地工程实施决定；不代表临床结局或周期方案获批。

## 背景

ENG-02A 要从已有的追加式人工 SPPB 总分记录显示基线和复评序列。一次确认后可以出现新的更正草稿；缺失、无效和未确认记录不应进入分值图示。仓库没有获批准的周期访视关系或疗效标签。

## 选项

1. 只取每项评估最新版本：待确认更正会覆盖已确认结果的页面含义。
2. 只取最新已确认版本：工作人员看不到正在待确认的更正。
3. 同时返回最新版本与最新已确认版本，页面分列，图示仅使用已确认且有效的总分。

## 决定

采用第 3 项。只读 API 在服务端完成角色、研究和对象范围校验，按评估登记时间和 ID 排序，每项返回 `current` 与 `latest_confirmed`。页面列出草稿、缺失与无效状态，零分只在确有已确认有效记录时绘制；没有确认版本时显示未知。仅展示描述性原始值，不计算疗效、周期终点、候选等级或建议。

## 后果

读者可以区分已确认值与待更正值，且不会把缺失误当零。已有迁移和数据模型不变；每次读取有审计。数据尚无批准的周期关系，因此排序是登记顺序而非计划访视时间线；训练完成率与 RPE 等指标待其数据功能实现。

## 重新评估触发条件与批准人

如批准的周期方案、结局定义和角色范围入库，需重新设计周期聚合及版本选择，并经项目数据与临床负责人审查。此 ADR 仅说明当前合成演示的工程选择，不是临床规则签核。
