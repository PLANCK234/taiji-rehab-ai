# ADR-0010 — 纯合成离线质量与对象级划分

**日期**：2026-10-31。**状态**：本地工程实施决定，不是研究数据或模型发布批准。

## 背景

ENG-03A 需要先验证数据质量和对象级隔离。现有数据库只有合成演示流程，研究二次使用同意、周期终点和疗效标签均未批准。

## 选项

1. 直接从业务库导出并把复评变化当标签：会越过同意、终点与标签审批。
2. 使用固定生成器产生明确标记的虚构记录，只验证质量、重放和对象级切分。

## 决定

采用第 2 项。独立 `ml/` 项目生成 `synthetic_demo` 记录，不连接业务库。清单写明固定种子、模式版本、记录与划分哈希、`target=null`、`clinical_use=false`。质量校验区分真实零与空值，报告缺失原因和重复记录，遇结构错误停止。按完整对象 ID 划分并拒绝集合交叉、遗漏或额外对象；导出目录已有不同内容时拒绝覆盖。

## 后果

可重复练习离线 QA 与防泄漏，但输出不能用于临床疗效、V0 比较或研究发布。尚无时点特征或真实研究样本，未来需单独实现批准的数据提取、冻结、预测时点和目标审查。

## 重新评估触发条件与批准人

只有研究二次使用同意、协议、终点/标签和安全存储经相应负责人签核后，数据负责人和临床负责人才能审查真实数据流水线；本 ADR 不代表签核。
