# ADR-0024：macOS 本地 Demo 自动备份

日期：2026-11-21（北京时间）；范围：ENG-05 / AT-13 合成子集。

现有 Docker 数据卷提供持久化，但之前的手动备份工具在仓库外，不能随项目审查和复用。将 Python 标准库备份工具纳入 scripts，以 macOS 当前用户 LaunchAgent 调度，避免让应用容器获得 Docker 管理套接字。默认24小时、失败5分钟重试；不定义数据保留或删除策略。

使用 PostgreSQL 导出快照同时供 pg_dump 和源数据核对，隔离恢复到无网络 tmpfs 容器。只在完全验证成功后推进上次成功时间。代价是每次恢复需要短暂额外数据库资源，电脑/用户/Docker必须可用；不会后台唤醒电脑。恢复失败或强制退出需人工查看受保护的状态文件。

仅本地合成数据，文件700/600权限不等于加密；Research/临床准入、正式保留策略和Windows自动安装不在范围。无数据库迁移/API变更，不改变原卷。具体操作见 [备份说明](../operations/DEMO_BACKUP.md)。
