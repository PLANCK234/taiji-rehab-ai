# ADR-0024：合成任务反馈复核独立保存

日期：2026-11-23。状态：本轮授权范围内的工程实施；不是临床批准。

一周计划 A-02 要求保留分析并记录人工复核。现有任务反馈有追加修订和发布版本，直接在反馈上写“已复核”会混淆患者来源，并可能让患者更正后的内容继承旧结论。

因此新增独立复核表，引用精确反馈修订，按修订追加复核序号、人员、时间、结果和备注。工作人员仅可对当前且有关联任务的反馈写入，历史只读；患者新修订不继承复核。clinician/research_assistant 可写，既有 READ_ROLES 可读，每次由服务器重查范围；clinical_approver 保持只读，不把普通复核包装成临床确认。

复用对象锁、幂等收据、CSRF 和审计。模拟同意撤回阻断新复核，保留只读。任务撤回不抹去已发生的反馈，现有反馈可继续核对。结果只用“已核对/无法判定”，都不表示安全、质量、疗效或临床批准；备注不纳入既有 CSV。

代价：多一次读取和一张追加表；好处是患者事实、模型计数和人工意见可独立追溯。教学视频、动作选择、实时运行状态持久化和临床评分仍属各自任务，不以自报做了训练推断完成。
