# ADR-0017 — 可比较的姿态信号与可恢复保存

日期：2026-11-26。状态：工程实施决定；任务`DEMO-V2-15`。不新增临床评分规则。

## 问题与选择

v1把原始角度变化直接作为幅度展示，静态模型抖动可能掩盖小幅运动；视频随播放采样会因推理变慢跳过时间点；保存响应丢失后重新采集可能产生重复记录。比较直接截断“小角度”、只保留平滑结果、保留原值并附信号分析，选择第三项。

## 决定

- 新结果使用`pose-geometry-v2`，保留原始角度、原中位数和P5–P95幅度。连续可见片段内使用±250ms局部中位数（最多前后4点），端点/稀疏点保留原值；缺失或>1秒间隔切断片段，不插值。
- 对相邻可见三点，用实际时间间隔线性预测中点并计算残差，除以`√(1+w左²+w右²)`。残差至少7个时，以`1.4826 × median(abs(r−median(r)))`估计高频噪声代理。平滑幅度与3倍残差噪声比较，仅输出工程描述；真实曲率/模型漂移可影响估计，不据此确认动作达标、疾病或治疗阶段。
- 原v1计算函数保留，旧数据库结果和确认不重算。迁移0009仅扩大算法版本约束，存在v2数据时拒绝回退0008，避免修改或丢弃证据。
- 文件暂停后按媒体时间每200ms定位、等待解码和推理，再采下一时刻；最长5分钟。每段视频新建跟踪图，模型时间戳使用本段媒体时钟。摄像仍实时采样，停止/卸载释放资源。参见[MDN currentTime](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/currentTime)与[MediaPipe Web文档](https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker?tab=Web)。定位是浏览器媒体时间近似，不声称精确逐编码帧解码。
- 待保存输入与固定幂等键只留在当前页面内存；响应失败后允许重试，锁定重新采集/修改输入直到保存或明确放弃。提交成功但详情读取失败时，从历史重新打开，不重复提交。历史列表不加载原始关键点列，也不返回逐帧series；详情仍保留完整证据。

## 验证与代价

固定种子合成角度轨迹中，静态RMS误差0.771072°→0.481609°，4°缓慢变化的平滑RMS误差0.086615°、P5–P95范围3.42°（理论3.6°）；两周期、每周期8秒的4°峰峰值波形，RMS0.091788°、范围3.96°。这是数值算法验证，不能推断人体视频精度。真实模型静态视频、故意慢推理、丢失提交响应后的幂等重试，以及v1升级/危险回退由自动化验证，详见[验证目标](../testing/AI_POSE_VALIDATION.md)。

中位数会改变短时峰值；平滑曲线必须和原始曲线同时展示。1.4826为正态尺度系数；实际误差非高斯或有时间相关性时，残差代理不能视为已校准误差。5Hz文件采样可能遗漏快速动作，不是任意运动分析器。页面关闭会丢失未保存输入，界面明确提示，不使用浏览器持久化健康数据。手机实机、真实连续动作、遮挡/辅具与专家标签仍需后续验证。

## 重新评估

获得专家标注或标准测量轨迹后，比较误差/短峰/漂移与多种滤波器，再新建算法版本。任务12依赖的评分锚点及任务13的最终阶段/计划映射由专家输入，不从本次噪声参数推导。
