# ADR-0008 — 姿态演示只生成合成画面

**日期**：2026-10-30。**状态**：本地工程实施决定；不代表影像、伦理或留存规则获批。

## 背景

S6-01 要求展示姿态演示入口和“算法尚未接入”提示。Q-01 与 Q-10 未给出真实影像同意、用途、权限和留存决定。已有模拟照片范围字段也不等于真实采集授权。

## 选项

1. 调用摄像头或本地文件选择，仅在浏览器预览：仍可能处理可识别影像，超出当前合成范围。
2. 提供固定图片样例：需要管理样例来源并防止混入真实照片。
3. 在页面内绘制合成 SVG 线条人物：不读取或保存任何真实图像，仅演示页面结构与状态。

## 决定

采用第 3 项。已登录且有研究/对象范围权限的工作人员可打开 `/participants/{id}/pose-demo`。按钮仅切换 React 内存中的合成 SVG 帧，清除按钮将状态归零；不提供摄像头、文件输入、上传 API、浏览器持久存储、姿态估计或评分。页面始终写明“姿态识别算法尚未接入”，并显示模拟照片范围只是记录状态。

## 后果

AT-12 的合成提示和不持久化边界可自动验证，无数据库迁移或新后端接口。此壳不能验证真实摄像权限、图像采集质量、存储安全或识别效果；这些能力保持关闭。

## 重新评估触发条件与批准人

只有 Q-01/10 的伦理、真实同意、权限、留存及托管决定签核后，才重新设计真实影像流程。当前批准仅为工程范围选择；临床、伦理和隐私批准人尚未指定。
