# ADR-0013: 单对象编号化实时 Demo 导出

日期：2026-10-31。状态：工程切片已采纳；真实研究数据导出未批准。

## 背景

REAL-01 要有从建档/人工评估/训练反馈/复评到趋势和导出的浏览器链路。周期冻结尚未实现，Q-07/Q-09 的真实字段、保留和数据发布权限尚未签核。仓库现有数据只允许合成 Demo。

## 决定

- `REAL-01F0` 增加单个已授权编号对象的实时 CSV 下载。沿用服务器端角色、研究和对象权限，允许现有临床/研究助理/临床复核角色；分析员当前无对象直读权限，不能导出。下载允许/拒绝均保留现有审计语义。
- 从数据库读取该对象的全部人工评估修订、已发生训练会话、反馈修订和事件存在事实。CSV 包含研究/对象编码、UUID、UTC 时间、记录者 UUID、状态、缺失原因、原始分值/时长/RPE；显式保留零与空、草稿与确认、旧版与新版。
- 不导出姓名/联系方式、密码、动作/疲劳/不适/事件等自由文本，也不输出临床等级、疗效结论或模型标签。响应禁止缓存，附行数和导出字节 SHA-256。前端只提供单对象下载，不提供批量接口。
- 响应明确标记 `live-demo`；哈希只核对这次导出的字节，不构成不可变快照。周期冻结、正式导出审批、字段/保留策略和真实数据使用仍需 REAL-01E/F 与 Q-07/Q-09。

## 验证

临时 PostgreSQL 完整 API 流程比较 CSV 行数、零/缺失、版本、哈希、无自由文本、跨对象/角色 403 与审计；真实 Chromium 通过对象页下载并核对内容。Research profile 继续 503。无真实患者数据、批量导出或原有数据库卷操作。

## 2026-11-07 增量范围：REAL-01F1

同一单对象、实时 Demo CSV 现增加人工原始观察的所有修订；沿用既有权限、审计和文件校验。增加来源与侧别结构化列，保留原始小数字符串、零和缺失状态；自由说明及更正原因仍不导出。此增量不改变上述真实数据、批量导出与冻结边界。

## 2026-11-07 增量范围：REAL-01F2

同一 CSV 增加手工合成周期容器及访视的全部修订。仅导出状态、版本、操作者/时间及同对象评估和训练观察 ID；周期/访视标签与更正原因留在受限业务界面，不进入 CSV。访视没有正式计划或发生时间，导出时间列只表示记录时间。关联 ID 如不属于导出对象则拒绝生成文件。此增量不构成研究方案日程、疗效分析或冻结数据集。
