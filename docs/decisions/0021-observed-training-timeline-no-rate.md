# ADR-0021: 合成训练观察序列不计算完成率

日期：2026-11-07。状态：合成工程切片采用；正式研究指标未批准。

ENG-02 的目标包括训练完成率和 RPE，但当前 D0 表只保存**已发生且已录入**的训练观察；手工周期也没有批准的计划次数、应到次数或正式日程。用已录入会话充当分母会把未录入或未发生的训练当成已完成，产生误导性比例。

ENG-02B 因此仅向获授权工作人员提供单个合成编号对象的只读序列：按会话发生时间/ID 排序，展示会话完成状态、实际分钟和该会话最新反馈版本的状态/RPE。无反馈或最新反馈为缺失时 RPE 为空；确实记录的 0 分钟保留为 0。接口不包含自由文本、患者自报、计划次数、完成率、安全或疗效结论。沿用服务端角色/研究/对象权限及读取审计，无数据库迁移。

将来若要完成周期级完成率，须先确定获批计划分母、未到与未记录语义、周期归属和修订规则，再另设任务与验收；本 ADR 不定义这些研究方案字段。
