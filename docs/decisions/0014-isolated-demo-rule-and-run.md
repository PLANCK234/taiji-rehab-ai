# ADR-0014 — 独立的合成 Demo 规则与训练流程

2026-10-31；状态：已实施的工程决定，非临床批准。

现有人工评估与训练观察已经有授权、审计、修订及 PostgreSQL 持久化。为交互演示新增 `demo_grade_results`、`demo_actions`、`demo_runs` 与可选展示资料；它们不替换原有实体。确认评估时写入版本化 `demo-rule-v1` 的结果、原始评估版本与依据。旧已确认记录若尚无 Demo 结果，在授权读取方案时补写一次；评估修订本身不变。

训练流程状态独立于原有“已发生训练观察”。结束时才创建一次既有 `training_sessions`，反馈仍走原有追加式 API；有反馈版本后才能将 Demo 流程标为完成。IV/UNASSESSED 不自动提供动作组合。规则和动作均标记 `DEMO_ONLY`，不解除 Q-03/Q-09、Research 准入或真实数据限制。

权衡：演示动作只有文字/几何占位，没有医学影像或获批剂量；暂停不计算净训练时间，结束时由研究人员录入实际分钟及可选实际完成动作。`0007_demo_completed_actions` 单独保存完成动作，未报时为未知，不按计划/浏览进度推断。显式中止写入原有训练观察，实际分钟保持未知，可后续补录反馈或报告事件。既有数据不回填处方或周期。

回退：`0006_demo_v2` 只可在空的临时测试库降级；本地有记录的库已经备份后向前迁移，不能直接执行破坏性降级。参见 [流程](../product/DEMO_USER_FLOW.md)。
