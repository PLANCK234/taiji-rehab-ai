# ADR-0018 — 先手工归组合成周期与访视

2026-11-06；状态：合成工程决定，非获批研究方案。

## 背景与选择

Q-05 尚未给出获批准的访视日程。现有人工评估与训练观察独立持久化，研究人员需要先验证归组与纵向查看，但不能推断访视周次或研究终点。

## 决定

每个合成编号对象可手工命名周期和访视。访视用追加版本保存到访情况、评估情况及已有评估/训练观察 ID；API 必须核对全部关联记录属于同一对象、工作人员有研究及对象授权、当前模拟同意有效，并要求 CSRF、幂等键与预期版本。没有记录时状态为未知；未到、拒测和未测均为明确人工记录。旧评估/训练行不迁移、不回填、不改变。对象页显示最新版本和修订历史，不计算完成率或疗效。

## 后果与复核

仅满足 REAL-01E0 的合成工程子范围。现有编号化 CSV 仍是未冻结的实时导出，不增加周期级研究结论。获批方案、实际访视日程、终点、冻结快照和真实数据准入仍需 Q-05/Q-06/Q-07 等机构决定；届时另建版本化方案映射，不把手工名称当正式方案。

## 2026-11-07 ENG-02C 展示补充

现有周期页已能显示最新访视、关联评估当前值、关联训练次数和旧修订。增加逐条关联训练的当前状态、实际分钟与最新反馈/RPE 时，复用同一编号对象的已授权只读训练序列，不创建新的周期汇总规则。旧访视修订仍只表示当时的手工关联；当前训练详情不回填成旧访视时点的快照。关联详情不可用时显示未知，不计算计划完成率或研究终点。
