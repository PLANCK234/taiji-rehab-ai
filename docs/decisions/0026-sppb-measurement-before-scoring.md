# ADR-0026：先交付可复算的坐站候选测量

- 日期：2026-11-26；任务：DEMO-V2-63；状态：工程实现，非临床规程批准。
- 背景：普通太极视频不能替代 SPPB 专项测试。现有 v3 是图像平面几何描述，本地实验室已有坐站候选算法；SPPB 评分表仍待 Q-14 确认。
- 决定：新增独立 `sppb-measure-v1` 纯函数及离线 CLI，接受现有合成 `PoseInput`；保留 v1/v2/v3 报告不变。该小任务不新增 API、数据库字段、评估草稿或临床评分表。
- 算法：固定机位下，以有效帧躯干长度中位数归一化髋中点高度，联合覆盖率较高侧的膝角，使用相对低/高状态和连续样本确认，记录首次候选起身及第五次候选站起；允许人工指定起点。
- 信号参数完整返回，算法版本与输入 SHA-256 一起用于复算。它们是工程检测参数，不能解释为 SPPB 计分阈值、正常值或临床合格线。
- 未知：不跨越缺失或采样间断推断转换；尝试窗口内缺失、多人、采样间断、手部不可见、未交叉、疑似撑扶及自报有支撑时，用时为 null。仍保留已观察到的候选转换与具体原因。
- 手部：腕到对侧肩部接近仅为交叉代理，腕接近髋部仅为撑扶疑似，均不能证明真实接触、独立完成或标准站直；输出始终 `protocol_compliance=unverified`、`requires_human_review=true`。
- 后续：DEMO-V2-64 才接入有授权、审计、幂等、持久化和逐项人工复核的服务；评分配置、来源、人工草稿再单独实现。禁止候选值直接驱动分级。新持久化迁移从 0024 开始，本次无需迁移。
- 验证与限制：见 [可执行验收](../testing/SPPB_MEASURE_VALIDATION.md)。视角、辅具和老年人性能尚未验证；3D、步速、平衡及评分均未包含。
