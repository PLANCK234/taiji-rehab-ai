# ADR-0012: 周期和临床规则未批准前只记录已发生训练观察

日期：2026-10-31。状态：工程切片已采纳；不代表临床方案获批。

## 背景

PRD FR-006 的正式训练会话应关联研究周期和规则版本，但 REAL-01E 周期尚未实现，Q-03/Q-09 训练适配及发布权限未签核。用户要求先构建可验证的纵向业务闭环，同时不得绕过审批。

## 决定

- `REAL-01D0` 只记录员工观察到的训练日期、动作、实际时长、完成状态和反馈；不保存计划动作、推荐剂量或临床分级。RPE 只接受 PRD 已列明的 6–20 录入域，未填为 null，不能解释为疗效或安全性。
- 每次训练有独立记录；反馈可保持未填，或追加“缺失”/“已记录”版本。更正需旧版本号和原因，所有版本保留。零分钟与未填时长分开，缺失反馈不能携带观测值。
- 授权工作人员可在反馈前独立记录事件，即使模拟同意后来撤回也可补报既往事件；平台不做严重程度、SAE、处置时限或通知承诺，需按机构既有渠道处理。Q-04/Q-12 保持未决。
- D0 表不伪造周期/规则版本；未来 REAL-01E/D 通过显式关联设计处理旧记录，禁止无证据回填或自动升级成处方。任何真实患者使用仍受 Research 关闭门禁约束。

## 后果和验证

前后端可用合成数据演练“已发生训练观察→事件→反馈→更正→历史”并进行研究数据质量工作。此切片不满足完整 FR-006 周期关联、FR-007 临床处置闭环或 REAL-01D。SQLite 单测、临时 PostgreSQL 迁移/API、Chromium 真实链路分别检查授权、幂等、更正、缺失与刷新持久化；真实数据/正式临床判断未执行。
